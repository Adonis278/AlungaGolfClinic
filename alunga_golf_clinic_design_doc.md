# Alunga Golf Clinic Website Design Document

## 1. Product Vision

Alunga Golf Clinic will become a premium, active, community-driven golf development brand that combines professional golf coaching with youth mentorship, character development, and global opportunity. The website should feel modern, energetic, trusted, and aspirational — a place where parents, students, schools, golf clubs, sponsors, and community partners immediately understand that Alunga is more than golf lessons.

**Core idea:**

> Alunga Golf Clinic teaches golf as a life skill — building confident players, disciplined leaders, and stronger communities through every swing.

## 2. Design Direction

The website should follow a modern, high-motion, editorial landing-page style inspired by Lorikeet’s bold SaaS storytelling approach, but adapted to golf, youth development, and sports performance.

The experience should feel:

- **Active:** movement, energy, swing motion, progress, transformation.
- **Premium:** clean typography, intentional spacing, strong contrast, polished visuals.
- **Youth-centered:** friendly, inclusive, uplifting, and mentorship-driven.
- **Trustworthy:** clear outcomes, program structure, safety, coaching credibility, partner logos, testimonials.
- **Global:** positioned for both the U.S. and East Africa with cultural connection and long-term impact.

## 3. Brand Personality

Alunga should speak with the confidence of a sports academy and the warmth of a youth-development nonprofit.

**Brand traits:**

- Professional but not intimidating
- Energetic but not childish
- Premium but accessible
- Community-focused but performance-driven
- Global but locally grounded

**Voice examples:**

- “Golf lessons for every age. Life skills for every future.”
- “Every swing has a lesson.”
- “From first grip to future leader.”
- “We don’t just build golfers. We build confidence, discipline, and opportunity.”
- “Coaching every swing, every age.”

## 4. Color System

The color palette should come directly from the Alunga Golf Clinic logo and flyer.

### Primary Colors

**Alunga Deep Green**  
Use for main backgrounds, hero sections, nav bars, footer, premium blocks, and CTA cards.  
Approx: `#003D1F`

**Fairway Green**  
Use for highlights, hover states, icons, badges, borders, and active states.  
Approx: `#1E6B2D`

**Golf White**  
Use for clean contrast, cards, text areas, and negative space.  
Approx: `#FFFFFF`

**Carbon Black**  
Use for typography, outlines, logo contrast, and premium UI accents.  
Approx: `#111111`

### Supporting Colors

**Soft Grass Tint**  
Use for background sections, youth-program cards, and low-contrast panels.  
Approx: `#EAF3E8`

**Sand Bunker Beige**  
Use sparingly for warmth, East Africa storytelling, scholarship cards, and community sections.  
Approx: `#D8C9A3`

**Metallic Silver Gray**  
Use for secondary text, dividers, dashboard mockups, and UI labels.  
Approx: `#B7B7B7`

### Color Usage Rule

Keep the visual identity mostly green, white, and black. Beige and silver should only support the design, not dominate it.

## 5. Typography

The typography should feel modern, bold, and athletic.

### Recommended Font Pairing

**Headings:** Sora, Space Grotesk, or Montserrat  
Use large, bold, slightly condensed headings with strong spacing.

**Body:** Inter, Poppins, or Manrope  
Use clean and readable body text for parents, schools, sponsors, and partners.

### Type Style

- Hero headline: very large, 64–88px desktop / 42–52px mobile
- Section headings: 42–56px desktop / 32–40px mobile
- Body text: 17–20px
- Labels/badges: 12–14px uppercase with tracking
- CTAs: 15–17px bold

## 6. Visual Style

### Overall Style

The website should use a dark premium base with bright golf-course imagery and clean white cards. The design should include layered motion elements that feel like a golf swing path, ball trail, or moving fairway lines.

### Visual Elements

- Curved swing-path lines around cards and section headers
- Floating golf-ball icons or subtle dimples as texture
- Dark green gradients with faint topographic/fairway patterns
- White rounded cards with thin green borders
- Action photos of coaching, putting, youth groups, families, and course practice
- Statistic cards with large numbers
- Side-by-side comparison sections
- Motion cards that slide, stack, or float as the user scrolls

### Border Radius and Cards

- Large rounded cards: 24px–32px
- Buttons: pill-shaped, 999px radius
- Image cards: 20px–28px radius
- Testimonial cards: 24px radius with soft shadow

## 7. Motion and Interaction

The site should feel active. Motion should support the sports brand without overwhelming the user.

### Motion Ideas

- Hero golf ball trail animation moving behind the headline
- Floating program cards showing “Short Game,” “Mental Game,” “Leadership,” “Swing Analysis”
- Scroll-triggered stat cards that count up
- Before/after swing improvement cards
- Hover states where cards slightly lift and reveal a green glow
- A horizontal ticker of outcomes: “Confidence Built,” “Swing Improved,” “Leadership Developed,” “Mentorship Created”
- Section transitions shaped like curved fairway lines

### Interaction Rules

Motion must be smooth, lightweight, and mobile-friendly. Avoid heavy animations that slow down the site.

## 14. Technical Direction

### Recommended Stack

- Next.js
- React
- Tailwind CSS
- Framer Motion
- Firebase or Supabase for forms and booking data
- Stripe for deposits and program payments
- Calendly or custom booking calendar
- Google Analytics / Firebase Analytics
- Instagram integration

### Core Features

- Responsive landing page
- Program pages
- Booking form
- Sponsor inquiry form
- Email notifications
- Testimonials CMS
- Blog / stories section
- Media gallery
- Admin dashboard for leads and bookings

### Performance Requirements

- Mobile-first design
- Fast image loading
- Lazy loading for media
- Optimized animations
- Lighthouse score target: 90+
- Accessible color contrast
- Keyboard navigable forms

## 15. Accessibility and Inclusion

Alunga’s website should reflect its mission of accessibility.

Requirements:

- Clear contrast between text and background
- Large, readable text
- Alt text on all images
- Form labels and error states
- No motion that causes discomfort
- Simple language for parents and youth
- Mobile-friendly booking
- Scholarship messaging visible, not hidden
